Escape the KUE

"Escape the KUE" ist ein Escape-Game, das im Rahmen meiner Maturaarbeit an der Kantonsschule Uetikon am See entwickelt wurde.
Das Spiel wurde mit Python und Pygame Zero programmiert. 
Der Spieler bewegt sich durch verschiedene Räume der Schule und muss versteckte Hinweise finden sowie Rätsel aus unterschiedlichen Schulfächern lösen, um innerhalb der vorgegebenen Zeit zu entkommen.

Voraussetzungen:
- Python 3
- Pygame Zero

Spiel starten:
Das Spiel wird über die Datei "Game.py" gestartet.
